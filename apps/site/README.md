# @latteart/site

The latteart marketing site — a static, zero-JS landing page.

The page is plain HTML + CSS on the workspace Vite+ toolchain. Design
tokens derive from the app's dark theme (`apps/web/src/index.css`),
retuned warm for marketing: espresso grounds, cream CTAs, caramel accent.

```bash
vp run @latteart/site#dev     # dev server
vp run @latteart/site#build   # static build → dist/
```
